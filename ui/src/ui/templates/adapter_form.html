AI prompt configuration

This adapter asks the LLM provider configured under Actions — AI (the same ACTIONS_AI_PROVIDER / model / API-key settings the summarizer uses — no per-adapter overrides) to produce one fresh item at each occurrence of the cron schedule below, for content that must be re-generated every cycle, like a weather report. It calls the model at most once per cron occurrence per prompt (the item id is keyed to both), so set the adapter poll interval well below the cron period; between occurrences every poll is a cheap no-op. Editing the prompt below regenerates on the next poll rather than waiting for the next occurrence.
